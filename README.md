# 书阅吧

一个极简的 Android 电子书阅读器，支持 EPUB、MOBI、PDF，按章节分页、连续阅读。

> 截图为书柜界面。

## 能做什么

- **单文件添加**：点右下角圆形 `+`，选择一个 `.epub`、`.mobi`（含 `.prc`）或 `.pdf` 文件，书柜中即出现这本书。添加时会先解析一次，打不开的文件会直接提示不是有效书籍。
- **三种格式同一套读法**：EPUB 按书内章节排版分页；MOBI 读正文与书内目录；PDF 直接按页渲染，一页就是一页。
- **书名取文件名**：书柜显示的文件名去掉扩展名，不看书里的标题元数据。
- **书柜一行三本**：封面分别取 EPUB 声明的封面、MOBI 内嵌封面、PDF 第一页；书里没有封面时显示带格式标签的占位封面。
- **目录带层级**：EPUB 的一级、二级、三级目录按原层级错位缩进，不会拍平；MOBI 用书内 NCX 目录；PDF 每页一条。
- **精确进度记忆**：自动记录读到第几章、第几页，重新打开从上次位置继续；PDF 记录读到第几页。
- **最近阅读置顶**：书柜按最近阅读时间排序，冷启动直接进入上次在读的书。
- **长按删除**：长按封面约 1 秒进入删除状态，把书拖到右下角「删除」即可移出书柜，不会删除手机里的原文件。

## 怎么用

1. 把 EPUB / MOBI / PDF 文件放在手机存储里（下载目录或任意文件夹均可）。
2. 打开「书阅吧」，点右下角 `+`，选中文件，书柜中出现这本书。
3. 点封面开始阅读，按下面的手势翻页；轻点屏幕左侧 1/4 区域可唤出目录。
4. 想整理书柜时长按封面，把书拖到「删除」按钮；下次打开会继续上次的阅读位置。

### 翻页与手势

阅读页没有工具栏和按钮，只在底部显示章节名与页码。

| 操作 | 效果 |
| --- | --- |
| 左滑 | 下一页 |
| 上滑 | 下一页 |
| 右滑 | 上一页 |
| 下滑 | 上一页 |
| 轻点屏幕左侧 1/4 | 唤出目录 |
| 系统返回手势或返回键 | 保存进度并返回书柜 |

翻页时页面跟手移动，松手后按拖动距离或速度决定是否翻过去；没到阈值会回弹。目录从左侧滑出，点条目直接跳到该章开头；目录打开时，系统返回会先关闭目录。

## 构建

- 最低系统版本：Android 8.0（API 26）
- 构建 release 包：

```powershell
.\gradlew.bat assembleRelease
```

生成的安装包位于 `app/build/outputs/apk/release/app-release.apk`。

仅当工程根目录存在 `keystore.properties` 时才会启用 release 签名；该文件缺失时构建仍可成功，只是产物未签名。
